# 🎬 [Film_director_check]

## Introduction

Every film director has a unique directorial style, characterized by specific elements such as color palette, editing rhythm, and camera movement.
This project learns these **quantifiable visual features** for each director. When a new video clip is provided as input, the system:

1. Predicts which director’s style it most closely resembles, and
2. Provides a **text-based explanation** detailing the specific features that led to this conclusion.

⚠️ Rather than understanding the content or directorial intent of a film,
this model compares features—quantified through metrics such as color saturation and cut length—against the learned patterns of various directors.
